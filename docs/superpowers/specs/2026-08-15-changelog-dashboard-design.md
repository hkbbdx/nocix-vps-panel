# 更新日志与首页展示设计规格

## 目标

增加 GitHub 可读的 `CHANGELOG.md`，记录每次功能、修复、安全和部署更新；同时在前端首页显示最近更新，
并提供独立的更新日志页面。默认简体中文，支持 English。

## 数据来源

- `CHANGELOG.md` 是项目根目录的人工维护发布日志，随代码提交到 GitHub。
- 前端使用一个类型安全的本地更新数据模块，避免运行时读取 GitHub、避免额外网络依赖。
- 每次发布修改代码时同步更新 Markdown 和前端数据。
- 每条更新包含日期、提交短 hash、类型、中文说明和英文说明。
- 更新文案不得包含 API Key、密码、代理凭据、验证码、Telegram Token 或其他敏感值。

## 前端

- Dashboard 增加“最近更新/Recent updates”面板，显示最近 5 条。
- 增加 `/updates` 页面，显示完整更新记录并按日期倒序。
- Layout 导航增加更新日志入口。
- 支持中英文切换，默认简体中文。
- 首页更新条目显示日期、类型标签、标题和最多 3 条说明。
- “查看全部/查看更新日志”链接进入 `/updates`。
- 无更新、加载和页面布局必须有可访问文本；静态本地数据不会产生加载错误。

## 版本记录格式

```markdown
## 2026-08-15

### 新增
- 支持 HTTP 和 SOCKS5 代理。

### 修复
- 修复任务状态和日志等级问题。
```

每次新发布放在文件顶部。技术提交仍保留 Git commit 作为可追溯链接，但用户描述使用中文和英文。

## 测试

- 更新数据包含合法日期、类型、短 hash、中文和英文文本。
- 首页显示最近更新且只显示前 5 条。
- `/updates` 显示完整记录。
- 中英文切换会更新更新日志文案。
- 导航包含更新日志入口。
- 原有任务、登录验证码、代理、PayPal、Telegram 和鉴权测试继续通过。
