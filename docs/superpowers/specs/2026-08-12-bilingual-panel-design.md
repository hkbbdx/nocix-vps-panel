# 双语面板设计规格

## 目标

为 NOCIX VPS 控制面板增加简体中文和 English 双语界面，首次访问默认使用简体中文，
用户切换后在同一浏览器中记住语言选择。

## 范围

- 登录页、侧边栏、顶部栏、仪表盘、任务、订单、日志、设置页全部支持中英文。
- 任务创建/编辑表单、确认弹窗、空状态、加载状态、错误提示和操作反馈支持中英文。
- 语言切换按钮放在面板顶部，并提供 `简体中文` 和 `English` 两个明确选项。
- 不翻译 NOCIX 返回的商品名称、网页错误、Selenium 日志和后端原始错误内容。
- API Key、密码和任务配置不写入语言存储项。

## 实现方式

- 新增轻量 `i18n` 模块，使用本地 TypeScript 词典，不引入大型国际化依赖。
- 语言类型为 `zh-CN | en-US`。
- 存储键为 `nocix-language`，只保存语言代码。
- 没有有效存储值时默认 `zh-CN`。
- 切换语言后通过 React Context 让所有页面立即重新渲染。
- 翻译函数支持简单插值，例如任务 ID、商品 ID和数量。
- 缺失翻译键在开发环境回退到 English 键名，避免页面崩溃。

## 语言切换

- AuthGate 页面也显示语言切换按钮，用户登录前即可选择语言。
- 登录成功后保留当前语言。
- 退出登录只清除 API Key 和查询缓存，不清除语言偏好。
- 浏览器禁用 `localStorage` 时使用内存默认值，不影响登录和任务功能。

## 测试

- 首次渲染默认显示简体中文。
- 选择 English 后界面主要文案变为英文。
- 刷新/重新挂载后保留选择的语言。
- AuthGate 和主面板都能切换语言。
- 翻译插值不会丢失任务 ID、商品 ID或数量。
- 原始 API 错误、商品名称和日志内容保持原样。
- 现有任务、订单、日志、设置、鉴权和构建测试继续通过。
